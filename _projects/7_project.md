This project is part of the CS-401 “Applied Data Analysis” course at EPFL taught by Prof. Maria Brbic.

This project explores navigation and human associations on Wikipedia through the game Wikispeedia, where players navigate from one article to another using only hyperlinks. By analyzing hubs, common and abandoned paths, and user strategies, the project provides insights into how Wikipedia’s structure influences navigation efficiency and patterns of common knowledge shared between users.
