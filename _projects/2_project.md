This project is part of the EE-559 "Deep Learning" course at EPFL, taught by Prof. Andrea Cavallaro.

The theme of the projects was "Hate Speech Detection". In this project we investigated using language models to detect coded hate speech, known as dog whistles, which are often hard to identify with traditional methods.
