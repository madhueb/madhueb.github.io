This project is part of the CS‑423 “Distributed Information Systems” course at EPFL taught by Prof. Karl Aberer.

It focuses on building a system to rank and retrieve documents based on their relevance to user queries. The system handles multilingual datasets and demonstrates scalable and effective document retrieval techniques.
